# Installer artwork and credits

`Assets/ElkaSoft.png` contains the ElkaSoft logo displayed inside the installer.
The installer file uses the separate `Assets/VBAN-Plug.ico` icon.

The Voicemeeter wordmark is from the [official Voicemeeter website](https://voicemeeter.com/wp-content/uploads/vb-audio-voicemeeter-logo.png).
The artwork credits distinguish ElkaSoft's plug-in from VB-Audio's VBAN protocol.
The installer does not install Voicemeeter.

## Assets

- `installer/Assets/ElkaSoft.png`: ElkaSoft logo
- `installer/Assets/VBAN-Plug.png`: square icon artwork
- `installer/Assets/VBAN-Plug.ico`: Windows icon, with 16, 24, 32, 48, 64, 128 and 256 px sizes
- `installer/Assets/Wizard.png`: tagged vertical installer sidebar
- `docs/images/vertical-tagged.png` and `vertical-untagged.png`: vertical artwork
- `docs/images/wide-tagged.png` and `wide-untagged.png`: landscape artwork
- `docs/images/social-preview-tagged.jpg` and `social-preview-untagged.jpg`: 1280 x 640 repository previews

Both artwork variants include the ElkaSoft maker credit. Tagged variants also
include the Voicemeeter wordmark and the `VBAN protocol by VB-Audio` credit.
See [NOTICE.md](../NOTICE.md) for branding and trademark notices.
